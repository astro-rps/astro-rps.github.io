Exercise 1: Plotting a Hertzsprung-Russell Diagram of the Globular Cluster M92 using Data from the Gaia Mission

The Gaia satellite has collected stellar positions, motions, and brightnesses for nearly two billion stars in the Milky Way. The file “GaiaM92.npy” contains example data from Gaia specifically for the globular star cluster Messier 92 (M92). To investigate the data, take the following steps:

  1. Load the .npy file into an array. Each row in this data file represents an individual star. Use np.load() to load the data from the file.

  2. Scatter plot of Color vs. Brightness: Now, create a scatterplot with the column bp_rp (a proxy for color) on the x-axis and phot_g_mean_mag (a proxy for luminosity) on the y-axis. Is the distribution in this plane uniform, or do you see patterns/sequences?

  3. Improve your scatter plot:

    • Invert the y-axis so that smaller numbers are at the top (since brighter stars have lower magnitudes).
    • Limit the x-range to -0.5 to 2.
    • Choose a smaller marker size and change the color.
    • Label both axes with meaningful labels, not just the column names.

  4. Compare your diagram to the one shown at this link: Cluster HR Diagram. Do you observe the same features in your plot? Exercise 2: Computing the Distance to the Cluster M92

The horizontal branch of the HR diagram (see Q4 of Exercise 1) is comprised of stars at roughly the same luminosity regardless of temperature. Since we have a sense of the instrinsic (absolute) luminosity of these stars, we can compared that to their observed luminosity to get a sense of their distance. For a globular cluster like M92, we can then average over the distance to these special stars to get a distance to the cluster. In this exercise, we’ll do exactly that!

  1. First, isolate the horizontal branch by filtering based on the phot_g_mean_mag column and the bp_rp column. In practice, you need four selections total which select for stars in this feature (e.g, mag > 15 and mag < 16 and similar for bp_rp). I recommend you impose phot_g_mean_mag < 15.5 as one of them to get the best possible results. Recall we can filter using this syntax in numpy: myarray[condition].
